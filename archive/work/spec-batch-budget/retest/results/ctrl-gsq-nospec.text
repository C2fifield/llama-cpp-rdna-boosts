## 1. System Overview

ForgeQueue is a distributed job-processing platform built around a **persistent, priority-aware work queue** backed by a PostgreSQL table (`forge_jobs`) and a Redis Streams layer for hot-path dispatch. Producers enqueue jobs; workers dequeue, execute, and report outcomes. The system guarantees at-least-once delivery, bounded retry semantics, and producer-facing backpressure.
