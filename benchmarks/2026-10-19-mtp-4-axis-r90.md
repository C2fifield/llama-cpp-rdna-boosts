# Adaptive-MTP four-axis gate on r90 (2026-10-19) -- async graph-input path, default-on

Dated record for the r90 release gate (`WORKLOG.md` 261019.009).  Protocol: **Protocol A** of
[`mtp-adaptive-methodology.md`](mtp-adaptive-methodology.md): `-n 3000` (rule 0), **reasoning pinned per
axis** (`--reasoning on` for R, `off` for P/C/K), `--seed 42 --temp 0 --single-turn --no-display-prompt
-c 32768 -b 2048 -ub 2048 -ctk f16 -ctv f16 -fa auto -ngl 99 -lv 4`, one run per cell, the MTP head built
into each GGUF (no `-md`), `--spec-draft-n-max 3` for `draft-mtp`.

Prompts (`prompts/`, hashes in `prompts/README.md`): `reasoning.txt` (R), `prose-rdna-boosts.txt` (P),
`code-python.txt` (C), `recall.txt` (K).

## Verdict

**PASS.**  Rule 0 (length/reasoning): both honoured.  Rule 1 (acceptance): healthy on every cell (0.577 to
0.992), identical between arms on the dense model and the 2-GPU MoE model, no collapse.  Rule 2 (MTP must
not lose to plain): `draft-mtp` beats plain on all 12 cells (1.9x to 2.9x).  Rule 3 (same-seed
determinism): the dense 27B text is byte-identical across arms (`5b1f6469ec6b`), and 81 of 81 recorded
acceptance values agree across arms where the model itself is deterministic.  Rule 4 (purity range): not
used as a gate here (fixed `n3` is inside `n_max <= 7`; equality above it is out of scope).  The async
graph-input default is worth **+1 to +2 %** on the dense model and **+6 % (plain) to +12.4 % (MTP)** on the
2-GPU MoE model, with no acceptance or purity change.

The 1-GPU 35B-A3B prose cell is the only row that is not exactly comparable between arms, and the repeats
above show it is not comparable **within** an arm either: it is the documented model-level
nondeterminism, which r90 neither causes nor fixes (it is also present with the async path off).
